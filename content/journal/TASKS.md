# Задания большим моделям — Журнал LOVII

Как выдавать: скопируй модели блок «Общее задание» + один блок «Статья N».
Файлы стратегии и брифа — в `lovii-site/content/journal/`.

## Общее задание (ко всем статьям)

> Ты — автор журнала LOVII. Прочитай `STRATEGY.md` (курс, канон цифр, правила)
> и свой файл `brief-00N-*.md`. Напиши статью строго по брифу.
>
> Формат выдачи:
> 1. `meta`: title (≤60), description (120–160).
> 2. Текст статьи в markdown: лид → разделы H2 → вывод с CTA.
> 3. FAQ-блок: 3–4 вопроса с короткими ответами.
>
> Жёсткие запреты: цифры только из STRATEGY (не выдумывать); без гарантий
> доходности и сроков; без жаргона; внутренние ссылки — минимум 2, URL только
> английские. Если факта нет в брифе и стратегии — не пиши его, пометь [нужен факт].
