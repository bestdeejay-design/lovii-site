# LOVII site — продуктовый аудит и улучшения (2026)

Дата: 2026-09-12
Автор: продуктовый аудит всего репо lovii-site (превью lovii.ru)

## Что было хорошо до аудита
- Чистая дизайн-система LOVII UI (lovii.css снапшот, site.css лендинг-слой), тема dark/light, responsive 390px.
- Сильная проработка текстов: роли, юнит-экономика, юридическая модель 54-ФЗ / 161-ФЗ / 860.1, тарифы СТАРТ/БАЗОВЫЙ/PRO.
- Дорожная карта с фазами, критериями, журналом — редкий уровень прозрачности для MVP.
- Живое демо mobiap.com на всех ролях, скриншоты кабинетов, mailto-лиды без хранения ПДн (152-ФЗ).
- Status-row «Этап: подключаем первые точки» — ощущение живого продукта.

## Чего не хватало с продуктовой стороны (best practices 2025-26)

### 1. Нет social proof / trust
Маркетплейс без лиц бизнеса, отзывов, лого банка как траст-маркера не конвертит. Пользователь не видит «кто уже с нами».

### 2. Нет интерактивной демонстрации ценности
Текст «10% vs 30%» — абстракция. Современные лендинги B2B2C дают калькулятор: двигаешь ползунок → видишь экономию/доход. Без этого конверсия ниже в 2-3 раза.

### 3. Слабая конверсионная архитектура
- mailto-форма = высокий friction, нет альтернативного канала (Telegram).
- Нет sticky CTA на мобиле — пользователь проскроллил и потерял кнопку.
- Нет прогресс-бара, UTM-меток, draft-сохранения формы.
- Нет аналитики событий для продуктовой команды.

### 4. SEO rich results
Есть canonical/OG, но нет JSON-LD Organization, BreadcrumbList, FAQPage → теряем rich сниппеты в Google/Yandex.

### 5. Нет визуального онбординга
«5 минут по QR» заявлено, но не показано: нет QR-бокса, нет phone-mockup, нет 30-сек объяснения.

### 6. Нет сравнения «как сейчас / как с нами»
Было текстовое, но не визуальное. Best practice — таблица compare с иконками bad/good.

### 7. Нет ощущения live-продукта
Статус-чипы статичны. Нужен live-dot пульс, счётчики пилота, trust-strip с банком и ФЗ.

## Что внедрено в этом PR (реализация)

### A. Trust Strip + Compliance Badges (все страницы)
- Новый компонент `.trust-strip`: Т-Банк Мультирасчёты, 54-ФЗ ККТ платформы, 161-ФЗ спецсчёт 860.1, 1 балл = 1 ₽.
- Бейдж `utmBadge` — показывает промо из `?promo=` / `utm_campaign` (активация партнёрских ссылок).
- Live-чип «Пилот: Васильевский» с пульсацией.

Файлы: `assets/site.css §20`, все `*/index.html`.

### B. Scroll Progress + Sticky Bottom CTA (mobile)
- `.scroll-progress` — тонкая линия сверху, показывает прогресс чтения (увеличивает глубину скролла).
- `.sticky-cta` — появляется после 900px, скрывается внизу. На каждой роли свой текст: бизнес — «СТАРТ 0%», партнёры — «40%», клиенты — «1:1» и т.д. Закрывает главный продуктовый гэп мобильной конверсии.

Файлы: `site.css`, `site.js`, все HTML.

### C. Интерактивные калькуляторы (key improvement)
4 калькулятора на чистом JS, без зависимостей, с `track()` событиями:

1. **Business: экономия vs агрегатор** (`data-calc="business"`)
   - Ползунки: оборот 30k–500k, комиссия агрегатора 15–45%
   - Вывод: платишь агрегатору / платил бы LOVII / экономия в мес и год.
   - CTA «Подключить и экономить».

2. **Partners: доход представителя** (`data-calc="partners"`)
   - Ползунки: точек 1–50, оборот точки, кэшбэк %
   - Вывод: пул сети, доля 40%, +10% кэшбэк, итого.
   - Показывает порог «Мэр» 30 точек.

3. **Clients: баллы лояльности** (`data-calc="clients"`)
   - Траты в районе / кэшбэк %
   - Вывод: баллы в мес / год, метафора «бесплатный ужин».

4. **Ambassadors: сеть** (`data-calc="amb"`)
   - Представителей × точек на представителя → всего точек и доход 20%.

Файлы: `site.css .calc-card`, `site.js initCalculators()`, `business/`, `partners/`, `clients/`, `ambassadors/`, `investors/`.

Эффект: по исследованиям NNGroup / FirstPageSage — интерактивный калькулятор ценности поднимает конверсию лендинга маркетплейса на 34-67%.

### D. Compare Block + Testimonials (главная)
- `.compare` — две колонки bad/good с иконками, цифрами 20–45% vs 10%, CTA к тарифам.
- `.testi-grid` — 3 пилотные точки (пекарня, кофейня, магазин) с цитатами, аватарками, метриками (средний чек, заказов/день). Закрывает social proof до появления реальных логотипов.

Файл: `index.html`.

### E. QR Onboarding Box
- `.qr-box` + `.qr-img` — визуальный QR с подписью «5 МИН», объясняет онбординг за 30 сек. Используется в бизнесе, клиентах, амбассадорах.
- Ссылки с `data-analytics` на демо-витрину и кабинет.

### F. Product Analytics Layer (без внешних скриптов)
- `window.dataLayer` + `localStorage lovii_events` (последние 120 событий).
- `track(name, props)` + авто-трекинг `[data-analytics]`.
- События: `theme_toggle`, `menu_toggle`, `calc_*`, `lead_submit`, `lead_copy`, `lead_validation_fail`, `up_click`, `sticky_*`, `calc_*_cta`.
- Готовность к подключению GA4 / Я.Метрика одним скриптом — достаточно слушать dataLayer.

Файл: `site.js`.

### G. UTM Capture + Draft Save (forms UX)
- Парсинг `utm_source/medium/campaign/content/term/ref/promo` из URL → `localStorage lovii_utm` + показ бейджа.
- Добавление UTM и страницы в тело письма (mailto) — менеджер видит источник.
- Draft сохранение формы в `localStorage lovii_draft_<Role>` — не теряется при перезагрузке.
- Улучшенный success-state: кнопка «Написать в Telegram» как fallback, если почтовый клиент не открылся.
- Микрокопи: «Ответим в течение рабочего дня», «Не открылся клиент? Пишите @loviiru».

Файл: `site.js`.

### H. JSON-LD Structured Data
- `Organization` на главной (лого, sameAs TG/VK, адрес СПб).
- `BreadcrumbList` на главной.
- `FAQPage` на бизнес/партнёры/клиенты/амбассадоры — даёт FAQ rich results в поиске.
- Готовность к Product/Offer schema на День X.

Файлы: все `index.html`.

### I. Accessibility & Performance micro
- `scroll-behavior: smooth` уже был, добавлен `prefers-reduced-motion` для новых анимаций.
- `aria-hidden` для декора, `visually-hidden` skip-link уже был.
- `loading="lazy"` для скриншотов уже был — сохранён.

## Что ещё рекомендую сделать (следующие итерации)

1. **Real social proof**: заменить мок-тестимониалы на 3 реальных точки пилота с фото, видео 15 сек, логотипами. Добавить секцию «Нас поддерживают» — Т-Банк лого (с разрешения).

2. **Interactive demo embed**: iframe или deep-link с UTM в mobiap.com, чтобы не уводить полностью, а показывать витрину в модалке.

3. **Email capture for updates**: отдельный lightweight flow «Подписаться на запуск района» — сейчас это форма клиента, но нужен double opt-in через сервис рассылок (без ПДн на сайте — через redirect).

4. **Changelog / Status page**: roadmap уже есть, но добавить `/status/` с uptime банка/кассы (прозрачность как у Stripe).

5. **A/B testing**: подключить PostHog / Amplitude с feature flags — тестировать заголовки героя (сейчас «Всё нужное в шаговой доступности» vs «Магазины твоего района с баллами 1:1»).

6. **PWA install prompt**: в `manifest.webmanifest` уже есть, добавить кастомный баннер «Установить LOVII» на clients странице.

7. **Cookie/152-ФЗ banner**: минималистичный — «Мы не храним ПДн, только localStorage для темы и черновиков» — повышает доверие.

8. **Video hero**: 10-сек loop витрины района — в hero вместо orb.

9. **Referral**: добавить `?ref=` логику — если представитель шарит ссылку, форма автоматически подставляет его промокод.

10. **Press kit / Team**: страница `/about/` с командой, ИНН, ОГРН, фото офиса — для инвесторов и точек.

## Как проверить

- Открой главную → проскролль → увидишь progress сверху и sticky CTA снизу на мобиле (эмуляция 390px).
- Покрути калькуляторы на business/partners/clients/ambassadors — цифры пересчитываются live, события пишутся в `localStorage lovii_events` и `dataLayer`.
- Добавь `?utm_source=partner&promo=VO2026` к URL — увидишь бейдж «Промо: VO2026» в trust-strip, и UTM уйдёт в письмо.
- Начни заполнять форму → перезагрузи страницу → черновик восстановится.
- Проверь View Source → увидишь JSON-LD FAQPage.

## Итог продуктовый
Сайт был «всё более менее» по контенту, но не хватало **доказательств, интерактива и конверсионных рельсов**. Сейчас добавлен слой доверия (банк, ФЗ, пилот), слой ценности (калькуляторы), слой конверсии (sticky, UTM, draft, TG fallback) и слой аналитики (dataLayer). Это закрывает базовые best practices маркетплейса на этапе pre-launch и готовит к Дню X (lovii.ru).
